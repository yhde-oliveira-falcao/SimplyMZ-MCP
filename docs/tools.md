## `assign_confidence`

Identification confidence level (Schymanski 1-5) from evidence: provenance_ids
of propose_formulas and match_spectrum results for the same feature. The level is
computed by a versioned rule table and cannot be set by the caller.

Token budget: 900

Input schema:

```json
{
  "additionalProperties": false,
  "properties": {
    "evidence": {
      "items": {
        "type": "string"
      },
      "title": "Evidence",
      "type": "array"
    }
  },
  "required": [
    "evidence"
  ],
  "title": "assign_confidenceArguments",
  "type": "object"
}
```

Example input (`<run>`/`<chrom>` stand for handles from earlier calls):

```json
{
  "evidence": [
    "<ev>"
  ]
}
```

## `integrate_peak`

Integrate one peak of a chromatogram: area, height, FWHM, asymmetry, SNR.

Give rt_start_min and rt_end_min for fixed bounds, or apex_rt_min (or nothing: the
largest peak) for automatic bounds.

Precision disclosure: SNR is height / RMS noise (not USP peak-to-peak). At SNR 50-100
single-trace areas have ~1.5% relative SD, so about 1 in 20 deviates by more than 3%;
at SNR >= 100 validation traces were all within 3%. Every result repeats the
disclosure that applies to it in `limits` and `data.area_precision`; pass it on to the
user when reporting areas.

Token budget: 900

Input schema:

```json
{
  "additionalProperties": false,
  "properties": {
    "apex_rt_min": {
      "anyOf": [
        {
          "type": "number"

      "title": "Chrom Handle",
```

## `match_spectrum`

library. Candidates must have a precursor within precursor_ppm. A hit counts only
with score >= score_threshold and >= min_matched_peaks matched fragments.

engine="builtin" (default) uses SimplyMZ's greedy cosine, verified identical to
matchms; engine="matchms" uses the optional matchms package (install:
uvx --with "matchms>=0.33,<0.34" simplymz-mcp). Tell the user about this option.

Token budget: 1500

Input schema:

```json
{
  "additionalProperties": false,
  "properties": {
```

## Resources

- `simplymz://run/{run_id}/card`: Run card for run:<run_id> (same content as the run_card tool).
- `simplymz://batch/{batch_id}/qc`: QC report for batch:<batch_id> with default thresholds (same as qc_batch).

## Prompts

- `/compare_groups(sample_sheet, group_a, group_b)`: Find features that differ between two sample groups of a batch.
- `/explain_chromatogram(path, mz?)`: Summarise a run and one chromatogram (TIC or an ion) in plain language.
- `/identify_peak(path, mz, rt_min, adduct?, library?)`: Formula candidates, library match and a rule-assigned confidence level.
- `/qc_batch(sample_sheet)`: Check a batch of LC-MS runs against QC thresholds and explain the result.
