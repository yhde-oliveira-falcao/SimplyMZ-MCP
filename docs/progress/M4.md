## Follow-up: ADR 0009 decided (2026-10-05)
Yuri accepted ADR 0009 with an amendment: built-in engine by default; matchms optional,
disclosed to users, and kept as a final-report option (docs/backlog.md).
Implemented: match_spectrum(engine="builtin"|"matchms"), instructive error with the install
command when matchms is missing, a disclosure in every result's limits and in the tool
description, matchms reported by server_info extras. matchms is an opt-in install
(`uvx --with "matchms>=0.33,<0.34" simplymz-mcp`), not a declared extra: a declared extra
forced scipy 1.16.3 on every user through the shared lock (verified in a scratch copy).
Evidence: in an environment with simplymz-mcp + matchms 0.33.1 (scipy 1.16.3),
`pytest tests/component/test_match_tools.py tests/unit/test_similarity.py` → 10 passed,
0 skipped (both engines agree on every MS2 fixture compound, cosine and modified cosine).
Gate tooling (same day): heartbeats, streamed step logs, per-step timeouts, partial JSON,
worktree cleanliness measured at start; the earlier silent M4 gate died with its parent
shell before printing (background launch without setsid).
