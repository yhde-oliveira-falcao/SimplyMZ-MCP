# Data used by SimplyMZ

Nothing below is bundled except the synthetic fixtures. Downloads are opt-in.

## Bundled: synthetic fixtures (tests/fixtures/)
Generated by `simplymz_mcp.synth` (`scripts/generate_fixtures.py`): 20 mzML runs with
ground truth, a sample sheet and a synthetic MS/MS library. Licence: CC0-1.0 (generated
data). Real compound names and formulas; chromatographic behaviour and fragment spectra are
invented and must not be used as reference data.

## Spectral library (scripts/download_library.py, opt-in, never bundled)
MassBank release 2026.03 (github.com/MassBank/MassBank-data): `MassBank_NISTformat.msp`
(137 MB) has no licence field, so licences are read per record from `MassBank.json`
(535 MB, Bioschemas JSON-LD with a `license` per record) and written into each MSP record
as `Comments: licence=...; accession=...`. Licences vary by record (e.g. CC BY, CC BY-SA);
match_spectrum reports the licence of every hit. Checked on 2026-10-05 against the first
3 MB / 0.8 MB of the two files: 750 of 776 parsed records received their licence.
NIST libraries are never supported for redistribution.
